WhatNext? — Privacy Policy

Last updated: August 2026  ·  Version 1.0.0

Short version: WhatNext? stores everything locally on your device. We collect nothing, sell nothing, and upload nothing. Your data never leaves your browser.

1. What data we process

To generate personalised recommendations, WhatNext? reads the following from your browsing activity:

  • Page titles — the <title> of pages you visit (max 200 characters)
  • Page URLs — to identify topic categories and apply the domain blocklist
  • Meta descriptions — the <meta name="description"> tag (max 300 characters) to understand page content
  • Search queries — only when you search on Google, Bing, or DuckDuckGo

This data is processed entirely on your device using a local interest model stored in IndexedDB. Raw page content (article text, images, forms) is never read.

2. What we never read

✗ Passwords ✗ Form inputs ✗ Payment pages ✗ Banking sites ✗ Login pages ✗ Health data

Pages containing a password input field, or whose URL path contains /login, /signin, /checkout, /payment, or /account/security, are automatically skipped — no signal is sent at all.

A configurable domain blocklist (bank, paypal, login, accounts.google.com, etc.) is enforced by default, and you can add any domain you like.

3. Where data is stored

All data — your interest profile, recommendation history, feedback, preferences, and API keys — is stored exclusively in your browser's IndexedDB (local to this device and browser profile). Nothing is synced to any external server by default.

4. Optional external API calls (BYOK)

WhatNext? supports optional "Bring Your Own Key" integrations. If you choose to enter an API key in Settings, the extension will make calls directly from your browser to that provider's API:

  • TMDB — to fetch live movie recommendations
  • Google Books API — to fetch live book recommendations
  • GitHub API — to fetch trending repository recommendations
  • NewsAPI — to fetch personalised news headlines
  • Groq / Anthropic — to generate AI-written reasoning for recommendations

These calls are made directly from your browser to the respective provider. WhatNext? never proxies, logs, or sees these requests. Your API keys are stored only in your browser's local IndexedDB — never on our servers (we have none).

All external API calls include only the minimum data needed (e.g., a search query derived from your interest tags — not your browsing history).

5. Optional MCP sync

If you opt-in to MCP sync in Settings, a snapshot of your interest profile and preferences is sent to a local server on your own machine (default: localhost:8787). This never leaves your device and is off by default.

6. Data we do not collect

  • We have no servers, no analytics, no telemetry
  • We do not collect your name, email, or any personal identifier
  • We do not use cookies or tracking pixels
  • We do not share any data with third parties
  • We do not sell data

7. Permissions justification

  • All URLs (http://*/*, https://*/*) — Required to inject the content script that reads page titles and sends interest signals. Without this, the interest model cannot learn from your browsing and recommendations remain generic.
  • storage — To persist your interest profile, recommendations, and preferences in IndexedDB.
  • alarms — To periodically refresh recommendations in the background every 3 hours.
  • notifications — To show a daily recommendation notification.
  • contextMenus — To add a "What should I do next?" right-click menu item.
  • tabs — To open the dashboard when you click "Open feed" in the popup or notification.

8. Your rights and data deletion

You can delete all locally stored data at any time from Settings → Danger Zone → Clear all local data. Alternatively, clearing your browser's site data for the extension will remove everything.

9. Children

WhatNext? is not directed at children under 13. We do not knowingly collect any data from children.

10. Changes to this policy

If we make material changes, we will update the "Last updated" date above and, where required, notify users through the extension itself.

11. Contact

Questions? Open an issue on our GitHub repository or reach out via the Chrome Web Store support link.
